# Agenda

Este é o repositório do projeto **Agenda**, desenvolvido como parte do curso Full Stack Turbo.

## 📂 Sobre o Projeto

A Agenda é uma aplicação simples para gerenciar contatos e compromissos. O objetivo é praticar conceitos de desenvolvimento full stack, incluindo front-end, back-end e banco de dados.

## 🚀 Tecnologias Utilizadas

- **Front-end**: HTML, CSS, JavaScript
- **Back-end**: Node.js, Express
- **Banco de Dados**: MongoDB

## 📦 Como Executar o Projeto

1. Clone o repositório:
    ```bash
    git clone https://github.com/amarildorpg/agenda.git
    ```
2. Instale as dependências:
    ```bash
    cd agenda
    npm install
    ```
3. Configure as variáveis de ambiente no arquivo `.env`.
4. Inicie o servidor:
    ```bash
    npm start
    ```
5. Acesse a aplicação no navegador em `http://localhost:3000`.

## 🛠️ Funcionalidades

- Adicionar, editar e remover contatos.
- Visualizar compromissos em uma interface amigável.
- Pesquisar contatos por nome.
